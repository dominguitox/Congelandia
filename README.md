# Congelandia

## Requisitos

- PHP >= 8.3
- Composer
- Node.js
- Git

Opcional: Laravel Herd instala PHP, Composer y Node.js automáticamente (con PHP reciente).

## Instalación

```bash
git clone <url-del-repositorio>
cd Congelandia
composer run setup
```

## Desarrollo

```bash
composer run dev
```

Abrir http://localhost:8000

Base de datos: SQLite, se crea sola al migrar.
